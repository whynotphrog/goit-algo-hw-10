# Висновки до ДЗ10

## Завдання 1. Оптимізація виробництва

Для задачі оптимізації виробництва було використано лінійне програмування за допомогою бібліотеки PuLP.
Модель максимізує загальну кількість вироблених напоїв "Лимонад" та "Фруктовий сік" з урахуванням обмежень на ресурси.

Результат показує оптимальну кількість кожного напою та максимальну сумарну кількість продукції.

## Завдання 2. Метод Монте-Карло

Для обчислення визначеного інтеграла функції f(x) = x² на відрізку [0, 2] використано метод Монте-Карло.
Було згенеровано велику кількість випадкових точок, що дозволило наблизити значення інтеграла.

Отриманий результат було перевірено за допомогою функції quad з бібліотеки SciPy.
Різниця між результатами є незначною, що підтверджує правильність реалізації методу Монте-Карло.

## Висновки

Метод Монте-Карло дозволяє отримати наближене значення інтеграла з достатньою точністю, яка зростає зі збільшенням кількості випадкових точок.
Лінійне програмування є ефективним інструментом для оптимізації задач з обмеженими ресурсами.
